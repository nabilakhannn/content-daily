# Install — Content Daily LinkedIn Coach

## What you need first
- Claude Code → [claude.ai/code](https://claude.ai/code) (free to install)
- Chrome or Edge browser

---

## Start in 2 steps

**Step 1 — Open Claude Code**

Download and open it from claude.ai/code. It looks like a chat window.

**Step 2 — Paste this prompt and press Enter**

```
Please run this bash command now to install the coaching system:

mkdir -p ~/.claude/skills/content-daily && curl -sL https://raw.githubusercontent.com/nabilakhannn/content-daily/main/SKILL.md -o ~/.claude/skills/content-daily/SKILL.md && echo "Installed"

Once you confirm it ran, run /content-daily.

You are my personal LinkedIn coach. Walk me through every step automatically. Ask me one question at a time, wait for my answer, then move to the next step yourself. When setup is complete, write my first post and deliver the full package. I don't need to know anything technical — just guide me.
```

Claude installs everything and starts your first session. You never touch the terminal.

---

## What happens next

**First session (~10 min):** Claude asks you questions to build your positioning, voice, and offer. You answer. It saves everything automatically.

**Every session after (~7 min):** Open Claude Code, type `/content-daily`. Claude researches your niche, picks 3 topic options with the post type and framework already chosen, writes in your voice, and delivers the full package.

**After 72 hours:** Come back and tell Claude how the post did — likes, comments, impressions. It logs performance and adjusts your next post to match what's working.

---

## If something goes wrong

Paste whatever error you see into Claude Code. It will fix it.
