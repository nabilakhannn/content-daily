# Install — Content Daily LinkedIn Coach

## What you need first
- Claude Code installed → [claude.ai/code](https://claude.ai/code)
- Chrome or Edge browser (for the swipe file extension)

---

## Install in 30 seconds

Open your terminal (Mac: press `Cmd+Space`, type `Terminal`, press Enter) and paste this one command:

```bash
mkdir -p ~/.claude/skills/content-daily && curl -sL https://raw.githubusercontent.com/nabilakhannn/content-daily/main/SKILL.md -o ~/.claude/skills/content-daily/SKILL.md && echo "✅ Content Daily installed"
```

You should see: `✅ Content Daily installed`

---

## Start your coach

Open Claude Code and paste this prompt exactly:

```
You are my personal LinkedIn coach. Run /content-daily now.

Do not wait for me to ask anything. Walk me through every step automatically. Ask me questions one at a time, wait for my answer, then move to the next step yourself. When setup is complete, write my first post and deliver the full package. I don't need to know anything technical — just guide me.
```

That's it. Claude will guide you through the rest — no tech knowledge needed.

---

## What happens next

**First session (~10 min):** Claude asks you questions to build your positioning, voice, and offer. You answer. It saves everything automatically.

**Every session after (~7 min):** Say "write me a post" or `/content-daily`. Claude researches your niche, picks 3 topic options, writes in your voice, and delivers the full package (post + image prompt + 5 comments + posting checklist).

**After 72 hours:** Come back and tell Claude how the post did (likes, comments, impressions). It updates your memory and gets smarter for next time.

---

## Need help?

If you see an error at any step, paste what you see into Claude Code and it will fix it.
